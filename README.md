# เปรม นมสด (Prem Nomsod) - Landing Page

เว็บไซต์ Landing Page สำหรับร้าน **"เปรม นมสด"** ร้านนมสด ขนมปังปิ้งเตาร้อน ปังเย็นทรงเครื่อง และของทานเล่น สไตล์เพื่อนฝูงยามค่ำคืน

---

## 🌟 จุดเด่นของเว็บไซต์
- **ดีไซน์สวยงาม ทันสมัย:** ใช้ Tailwind CSS โทนสีฟ้า-ขาว-ทองเนยปังปิ้ง พร้อมบรรยากาศไฟวอร์มไลท์ยามค่ำคืน
- **ฟอนต์สวยงาม:** ใช้ฟอนต์ Google Fonts ภาษาไทย (Kanit & Prompt)
- **ระบบแท็บกรองเมนู (Category Filter):** สามารถเลือกดูเมนูปังปิ้ง, เครื่องดื่ม, ปังเย็น, ของทานเล่น ได้อย่างสะดวก
- **แผนที่ปักหมุด Google Maps:** แสดงพิกัดร้านบนแผนที่ พร้อมปุ่มเปิดแอป Google Maps นำทาง
- **เชื่อมต่อเพจ Facebook:** มีปุ่มลิงก์ไปยังหน้าเพจ Facebook ทั้งบน Header, การ์ดข้อมูลร้าน และ Floating Button
- **Fully Responsive:** รองรับการเปิดใช้งานบนมือถือ แท็บเล็ต และคอมพิวเตอร์อย่างสมบูรณ์แบบ

---

## 📂 โครงสร้างโฟลเดอร์
```text
├── index.html            # หน้าเว็บหลัก Landing Page
├── logo.png              # โลโก้ร้านเปรม นมสด
├── เมนูร้าน/              # รูปภาพเมนูอาหารและเครื่องดื่ม
├── บรรยากาศในร้าน/       # รูปภาพบรรยากาศร้าน แสงไฟ และกลุ่มลูกค้า
└── README.md             # รายละเอียดโปรเจกต์
```
